# TastSelv kørselsfradrag flow

Screenshots of SKAT's TastSelv flow for entering the commuting deduction,
taken November 2026 (income year 2026). KmKroner's Summary and TastSelv guide
(T5.1, T5.2) mirror these steps.

1. **Period and addresses** — employment period, home (folkeregisteradresse)
   and work address; extra work addresses on the same route for triangular
   driving. `1-period-and-addresses.png`
2. **Days of driving** — a count per month, excluding home-office, holiday
   and sick days. `2-days-of-driving.webp`, `2b-days-of-driving-total.webp`
3. **Route** — distance per day (round trip). It's the actual driving
   distance from the official address, not necessarily the shortest route,
   without detours; train and bus use the car distance.
   `3-route.webp`, `3b-distance-per-day-help.png`
4. **Result** — SKAT calculates the deduction. More entries can be added
   (one per workplace, period or address). `4-result.png`

Open questions: how split shifts and bridge crossings are entered (see the
PRD's Open questions).
